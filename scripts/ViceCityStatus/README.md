# 🌴 ViceCityStatus

**ViceCityStatus** — скрипт для получения статуса сервера **Arizona Vice City**.

---

## 🚀 Возможности

* 📡 получение статуса сервера (ONLINE / NO RESPONSE)
* 👥 отображение онлайна
* 📊 отображение максимального количества игроков
* ⏳ отображение очереди
* 🐞 режим отладки (debug)

---

## ⌨️ Команды

* `/vcstatus` — проверить статус сервера
* `/vcdebug` — включить / отключить debug режим

---

## 📥 Установка

1. Переместите файл скрипта в папку:

```text
moonloader/
```

2. Убедитесь, что установлены зависимости:

* `LuaSocket`
* `LuaSec (ssl.https)`
* `dkjson` или `lunajson`

3. Поместите JSON библиотеку в:

```text
moonloader/lib/
```

---

## ⚙️ Особенности

* Автоматически обрабатывает редиректы
* Поддерживает fallback JSON библиотек
* Работает через HTTP/HTTPS

## ⚠️ Предупреждение

При отсутствии зависимостей:

* статус может не загружаться
* JSON не будет парситься
* HTTPS может не работать
