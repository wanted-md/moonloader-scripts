# 👨‍👩‍👧‍👦 FamilyNotify

**FamilyNotify** — продвинутый скрипт для лидеров и заместителей семьи на **Arizona RP (SA-MP)**.

Автоматически отправляет уведомления о жизни семьи в **Telegram**, ведёт подробную статистику и предоставляет удобный интерфейс для управления всеми функциями.

---

## 🚀 Возможности

### 📢 Уведомления

* 👤 Вступление, выход и исключение игроков из семьи
* 🔇 Муты, выговоры и чёрный список
* 🎖️ Изменение рангов, тегов и заместителей
* 💰 Баланс семьи, семейные монеты, налог за квартиру и премии
* 🚗 Семейный транспорт
* ⭐ Репутация семьи
* ⚔️ Семейные войны (Family War)
* 💬 Пересылка семейного чата и чата альянса в Telegram

---

## 📊 Статистика

* 📈 Учёт инвайтов по дням недели
* 🟢 Статистика онлайна
* 📅 Автоматический еженедельный отчёт
* 📤 Ручная отправка статистики
* 🗑️ Очистка статистики одной кнопкой

---

## 🔒 Права доступа

* 👑 Лидер имеет полный доступ ко всем настройкам.
* 🛡️ Для заместителей часть категорий ограничена.
* 🔐 Управление, финансы, репутация и другие важные уведомления принудительно включены и не могут быть отключены.

---

## 🛡️ Защита от дублей

Если скрипт одновременно запущен у нескольких членов семьи, уведомления будет отправлять только один клиент.

Приоритет отправки:

1. 👑 Лидер
2. 🛡️ Заместители

Это исключает появление дублирующихся сообщений в Telegram.
