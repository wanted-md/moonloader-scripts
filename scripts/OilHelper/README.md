# 🛢️ OilHelper

**OilHelper** — продвинутый скрипт для упрощения работы с нефтью на **Arizona RP**.

---

## 🚀 Возможности

* 📊 подсчёт и ведение статистики
* 🧾 логирование действий
* 🖥️ интерфейс на ImGui
* ⚙️ настройка параметров
* 🔄 элементы автоматизации

---

## ⌨️ Команды

* `/oh` — открыть главное меню
* `/ohm` — включить / отключить управление режимом

> ⚠️ Список команд может дополняться по мере разработки.

---

## 📥 Установка

1. Переместите файл скрипта в папку:

```text id="n6bwhl"
moonloader/
```

2. (При наличии) скопируйте дополнительные файлы:

* конфиги (`.ini`, `.json`)
* шрифты и ресурсы

3. Запустите игру и убедитесь, что **MoonLoader** установлен и работает корректно.
